# Remove a Git submodule

````ai
```bash
git rm <path>                      # e.g. third-party/slurm-sim
rm -rf .git/modules/<path>         # remove the cached copy of the submodule's repository
git config --remove-section submodule.<path> 2>/dev/null   # drop any leftover entry in .git/config
```

`git rm` does three things: it deletes the submodule's folder, removes it from the staging area, and takes its entry out of `.gitmodules`, staging that change for you. The other two lines remove what `git rm` leaves behind. Without them, adding a submodule at the same path later can fail with a "already exists" error.

Your repo has no commits yet, so the submodules are only staged. `git rm` works fine in that case. If it complains, use `git rm --cached <path>` to unstage the submodule, then delete the folder by hand.

For example, to remove the old `slurm-sim`:

```bash
git rm third-party/slurm-sim
rm -rf .git/modules/third-party/slurm-sim
git config --remove-section submodule.third-party/slurm-sim 2>/dev/null
```
````

If nothing has been staged yet:

````ai
That error happens because nothing in the repo is staged any more. `git status` shows `.gitmodules` and all four `third-party/` folders as untracked (`??`), even though they were staged at the start of this session. Probably a `git rm --cached` or `git reset` unstaged everything. `git rm` only works on files Git is tracking, so it can't find `third-party/slurm-sim`.

You'll need to remove it by hand:

```bash
# 1. Delete its block from .gitmodules
git config -f .gitmodules --remove-section submodule.third-party/slurm-sim

# 2. Delete its entry from .git/config
git config --remove-section submodule.third-party/slurm-sim

# 3. Delete the folder and Git's cached copy of the submodule's repository
rm -rf third-party/slurm-sim .git/modules/third-party/slurm-sim
```

Then stage the submodules you're keeping again:

```bash
git add .gitmodules third-party/caspir-digital-twin third-party/slurm_simulator third-party/slurm_sim_tools
git status   # each should show as "new file" (staged), with no trailing slash
```

`git add` stages each of these folders as a submodule, not as ordinary files, because each one contains its own `.git` file.
````
