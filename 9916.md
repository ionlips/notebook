# Neovim keyboard shortcuts

## Buffers

````ai
Your leader key is **Space**. Your config defines only a few buffer mappings, all in `lua/keymaps.lua`, `lua/find.lua` and `lua/netrw.lua`:

| Key           | What it does                                                                                                                                                                                                                                                                                     |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<Space>q`    | **Closes the current buffer but keeps the window open.** It switches to the previous buffer (`#`) if that buffer is still listed, otherwise it opens an empty one, then deletes the original. In special buffers such as netrw, help or quickfix, it runs `:quit` instead. (`lua/keymaps.lua:2`) |
| `<Space>w`    | Saves the buffer (`:w`).                                                                                                                                                                                                                                                                         |
| `<Space>f`    | Starts `:find ` so you can type part of a name and open a file. It uses fuzzy matching on `fd` output, which includes hidden files and skips `.git`. Tab completes the name. (`lua/find.lua:28`)                                                                                                 |
| `<Space>e`    | Opens or closes the netrw file explorer on the left (`:Lexplore`).                                                                                                                                                                                                                               |
| `<C-h/j/k/l>` | Moves between splits. These work on windows, not buffers, but you'll use them alongside the buffer keys.                                                                                                                                                                                         |

There are **no custom mappings for switching between buffers**, so you're using Neovim's built-in commands:

- `<C-^>` (Ctrl-6) switches to the previous buffer. This is the quickest way to flip between two files.
- `:ls` lists open buffers, and `:b <name or number>` jumps to one. `:b` also completes partial names with Tab.
- `:bn` / `:bp` go to the next or previous buffer.
- `]b` / `[b` do the same as `:bn` / `:bp`. Neovim 0.11+ maps these by default, alongside `]q`/`[q` for quickfix.
- `:bd` deletes a buffer, but it also closes the window. Your `<Space>q` avoids that.

Neovim turns on `hidden` by default, so you can switch away from a buffer without saving it first.

If you switch buffers a lot, adding `<Space>b` → `:b ` (like your `<Space>f` → `:find `) would give you quick buffer jumping.
````

## Windows

````ai
The only custom window mappings in your config move you between splits. They're in `lua/keymaps.lua:17-40`:

| Key     | What it does                                                                       |
| ------- | ---------------------------------------------------------------------------------- |
| `<C-h>` | Move to the split on the left                                                      |
| `<C-j>` | Move to the split below                                                            |
| `<C-k>` | Move to the split above                                                            |
| `<C-l>` | Move to the split on the right (a recent commit stopped netrw overriding this one) |

Everything else uses Neovim's built-in `<C-w>` commands:

**Creating and closing splits**
- `<C-w>s` or `:sp [file]` splits horizontally.
- `<C-w>v` or `:vs [file]` splits vertically.
- `<C-w>c` or `:close` closes the current window.
- `<C-w>o` or `:only` closes every window except the current one.
- `<C-w>q` quits the current window. Your `<Space>q` closes the buffer and keeps the window, so it's the opposite.

**Resizing**
- `<C-w>=` makes all windows the same size.
- `<C-w>+` / `<C-w>-` make the window taller or shorter. Put a number first to change it by more, e.g. `10<C-w>+`.
- `<C-w>>` / `<C-w><` make the window wider or narrower.
- `<C-w>_` / `<C-w>|` make the window as tall or as wide as possible.

**Moving windows around**
- `<C-w>H/J/K/L` moves the current window to the far left, bottom, top or right.
- `<C-w>r` rotates the windows, and `<C-w>x` swaps the current window with the next one.
- `<C-w>T` moves the current window to a new tab.
- `<C-w>p` goes back to the window you were in before.

**Notes on your setup**
- You haven't set `splitright` or `splitbelow`, so Neovim's defaults apply: `:vs` opens the new window on the **left** and `:sp` opens it **above**. Many people turn both on (`vim.opt.splitright = true`, `vim.opt.splitbelow = true`) so new splits open to the right and below.
- The netrw explorer you open with `<Space>e` takes up 25% of the width, and it opens files in the window you were last in. To create a file from netrw, press `%`; the file opens in that previous window (`lua/netrw.lua`).
- You can add a filename to the split commands, e.g. `:vs` then `<C-r>%`, or `:sp` with Tab completion. Your fuzzy `:find` also has split versions: `:sfind` and `:vert sfind`.
````
