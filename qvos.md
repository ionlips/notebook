# Markdown style guide

Keys and their respective mappings are enclosed within backticks. Keys which
have to be pushed together are connected via a hyphen (e.g., `control`-`space`
implies that `control` and `space` must be pushed down at the same time).
Conversely, keys which do not have to be pushed together, but instead follow
some kind of order, are simply separated (e.g., `control` `space` implies that
`control` must be pushed first and `space` must be pushed after, regardless of
how much time it takes between the two).
