22:52:32: Was able to get a keyboard shortcut for inserting the current time on
Desktop (running Ubuntu). Steps taken were as follows:

```shell
sudo apt install ydotool
echo 'KERNEL=="uinput", GROUP="input", MODE="0660", OPTIONS+="static_node=uinput"' | sudo tee /etc/udev/rules.d/80-uinput.rules
sudo usermod -aG input "$USER"
# Log out and log back in... should be enough, but I had to do a full restart.
systemctl --user enable --now ydotool
```

Create `~/.local/bin/insert-time`:

```sh
#!/usr/bin/env bash

sleep 0.4
ydotool type "$(date +%H:%M:%S)"
```

`chmod +x ~/.local/bin/insert-time` and bind it to `control`-`super`-`alt`-`t`
by going to Settings > Keyboard > View and Customize Shortcuts > Custom
Shortcuts > + Add Shortcut.
