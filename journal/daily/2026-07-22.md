# Wednesday, July 22, 2026

Spent some time trying to understand why nvim-treesitter would not install
properly on qllm. I have installed Tree-sitter version 0.26.9 which requires
glibc version 2.39, or greater, at compile-time. Thus, according to Claude, the
best course of action is to compile it from source myself. I did the following:

```shell
# Install `rustup` for Rust. Note that I chose not to modify my `.rc` files.
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Install Tree-sitter's CLI.
~/.cargo/bin/cargo install tree-sitter-cli \
    --locked \
    --no-default-features \
    --version 0.26.11
```

Switch the new binary for the old.
