I "reset" Desktop (i.e., deleted all my hidden directories and files) and upon
doing so, I realised that I had a custom executable within `~/.local/bin`
called `insert-time` that allowed me to enter the current time via a keyboard
shortcut. For reference, here are the steps:

1.  `sudo apt install ydotool`.
1.  `sudo usermod --append --groups input $USER`.
1.  `systemctl --user status ydotool`.
1.  Create `~/.local/bin/insert-time` through chezmoi:

    ```sh
    #!/usr/bin/env bash
    sleep 0
    ydotool type $(date +%H:%M:%S)
    ```

1.  Settings > Keyboard > View and Customize Shortcuts > Custom Shortcuts > +
    Add Shortcut.
