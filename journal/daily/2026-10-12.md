15:20:37: Annoyingly, installing Docker Desktop on macOS (which is the only way
to install Docker) results in the modification of your `.rc` file(s). In my
case, `.zprofile` and `.zshrc` were modified with the following changes to each
file, respectively:

```text
-# The following lines were added by Docker Desktop to add commands to your PATH.
-export PATH="$PATH:/Users/ilipsiuc/.docker/bin"
-# End of Docker Desktop section.
```

```text
-# The following lines have been added by Docker Desktop to enable Docker CLI completions.
-fpath=(/Users/ilipsiuc/.docker/completions $fpath)
-autoload -Uz compinit
-(( ${+_comps[docker]} )) || compinit
-# End of Docker CLI completions
```
