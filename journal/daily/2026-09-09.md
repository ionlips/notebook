# Wednesday, September 09, 2026

Looked for a GNU/Linux alternative for LookAway and came across [Stretchly]. I
installed it as follows:

```shell
curl -Lo ~/Downloads/Stretchly_1.22.1_amd64.deb https://github.com/hovancik/stretchly/releases/download/v1.22.1/Stretchly_1.22.1_amd64.deb
sudo dpkg -i ~/Downloads/Stretchly_1.22.1_amd64.deb
```

The documentation also mentions to install `libxss-dev` so that was also
installed via `sudo apt install libxss-dev`.

Unfortunately, Stretchly wouldn't open so

```shell
kernel.unprivileged_userns_clone=1
kernel.apparmor_restrict_unprivileged_userns=0
```

were both added to `/etc/sysctl.d/00-local-userns.conf`, followed by a reboot.
Unfortunately, this did not fix my problem at Stretchly still won't start. I
will come back to this later; for now, I will make use of Ubuntu's built-in
reminders via Wellbeing > Break Reminders in Settings.
