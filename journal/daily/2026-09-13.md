# Sunday, September 13, 2026

Installed yt-dlp on Desktop as follows:

```shell
curl -Lo ~/.local/bin/yt-dlp https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp
chmod +x ~/.local/bin/yt-dlp
```

As per its `README.md`, FFmpeg and yt-dlp-ejs are strongly recommended. They
were installed as follows:

```shell
sudo apt install ffmpeg
mkdir yt-dlp && cd yt-dlp
uv venv && source .venv/bin/activate
uv pip install yt-dlp-ejs
```

> [!NOTE]
> Any downloads from YouTube have to be done from within this virtual
> environment... I think. The `README.md` states that yt-dlp-ejs is required
> "for full YouTube support".

<https://youtu.be/bfWrTdB5VHg?si=gSsqjeE9eaVkIxTQ> was downloaded as follows:

```shell
yt-dlp --audio-format opus -x https://youtu.be/bfWrTdB5VHg?si=gSsqjeE9eaVkIxTQ
```
